# FinderPathBar

面向习惯 Windows「资源管理器地址栏」的 macOS 用户：在 Finder 窗口上方贴一条轻量地址栏，显示当前路径，并提供新建、重命名、剪切移动、收藏夹等快捷操作。

**当前版本：1.0.91**

## 下载

请到本仓库 **[Releases](https://github.com/yikeshu0611/FinderPathBar/releases)** 页面，在 **Assets** 中下载最新 `.dmg`（例如 `FinderPathBar-1.0.91.dmg`）。

## 安装与权限

1. 打开 DMG，将 `FinderPathBar.app` 拖到「应用程序」
2. 若系统拦截：系统设置 → 隐私与安全性 → **仍要打开**
3. 授予 **辅助功能** 权限（按提示也可开自动化），然后打开 Finder，地址栏会附着在窗口上方

## 主要功能

- **地址栏附着**：跟随当前 Finder 窗口，也支持其它 App 的打开/上传/保存对话框；`⌘L` 编辑路径，支持补全与回车跳转；第一行 **Xo** 关闭其他窗口、**Xa** 关闭全部窗口
- **路径导航**：上级目录、前进/后退、剪贴板路径跳转（goPth）、复制路径（CPth）
- **新建文件**：第 2 行 `dir / txt / …` 单击新建、双击新建并打开；可在设置中自定义 6 个后缀（`dir` = 文件夹）
- **文件操作**：F2 重命名、打开、复制 / 剪切 / 粘贴移动、废纸篓与撤销、Ext（扩展名注释）
- **当前文件夹搜索**：`⌘F` 按名称过滤
- **收藏夹**：固定在第 2 行，点 ★ 添加，支持分组菜单
- **设置**：图标/文字尺寸、背景色、开机启动、语言、新建类型、检查更新等
- **赞赏提示**：扫码支持；关闭后约 10 分钟再提示，「1天后出现」可暂缓一天；赞赏后点击「永久关闭」仅本地不再弹出
